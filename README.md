# MSA48MCCNP
*MSA-48 Methylation Classifier and Copy Number Profiler*
This repository accompanies our manuscript entitled "A DNA Methylation and Copy Number Profiling Strategy for Ultralow-Input Specimens". It is intended to replicate the described workflow locally.

The page [https://neuropathbasel.github.io/MSA48MCCNP/Supplements/CNV_plot_overview.html](https://neuropathbasel.github.io/MSA48MCCNP/Supplements/CNV_plot_overview.html) contains plotted data referenced in the manuscript. The HTML source code and the plot PNG files are contained in the [docs](https://github.com/neuropathbasel/MSA48MCCNP/tree/main/docs) directory.

The directory [crossNN_ND_IfP_20250912](https://github.com/neuropathbasel/MSA48MCCNP/tree/main/crossNN_ND_IfP_20250912) contains the code to train [crossNN](https://pubmed.ncbi.nlm.nih.gov/40481322/) with the reference set *ND_IfP_20250912* consisting of [GSE90496](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE90496), [GSE342206](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE342206), and [GSE342261](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE342261).
