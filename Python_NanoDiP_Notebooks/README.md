# Create files and folder structure needed by EpiDiP/NanoDiP 

The following step should be rund after for Sentrix ID a CNVplot.png a bin is created in R/SeSaMe. 

## In Jupyter notebook open
06_File_Folder_structure_4_EpiDiP_with_SeSaMeOutput_in_one_dir.ipynb
Adapt paths to your setup and save it as py. Run this python file in xTerm as outlined above.

EpiDiP/ NanoDip relies on unique sample names. Since different sample amounts and different thresholds for the binarisation of the beta values were used, Pseudo Sample Names were generated by combining the actual sample name, the input amount and the beta threshold. Delimiters were replaced by d for the beta threshold and p for the input amounts.

Each “Pseudo” sample is linked to a Sentrix ID in 

/data/nanodip_reports/Working_MSAsampleetDF.csv

In addition Methoverlap.csv are created for each input amount and beta threshold in this directory.
